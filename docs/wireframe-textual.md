# Wireframe textual

## Vista principal móvil

- **Topbar**
  - Logo FitForge
  - Botón modo oscuro/claro

- **Tarjeta Onboarding (si usuario nuevo)**
  - Título y subtítulo
  - Formulario 2 columnas responsive
  - Botón primario: "Crear mi plan"

- **Dashboard (si usuario existente)**
  - Bloque "Panel de progreso"
  - Grid de métricas tipo cards
  - Panel "Evolución de peso" (canvas)
  - Panel "Registrar sesión" (form simple)
  - Panel "Rutina recomendada" (lista con razón de recomendación)
  - Panel "Historial" (últimas sesiones)

## Comportamiento responsive

- Mobile first.
- Botones de alto contraste y área táctil amplia.
- Cards apiladas en pantallas pequeñas.
