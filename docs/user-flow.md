# Flujo de usuario (UX para principiantes)

1. **Apertura app**
   - Detecta tema + carga datos locales.
2. **Onboarding paso único guiado**
   - Inputs grandes, labels claras, validación inmediata.
3. **Dashboard inicial automático**
   - Resumen de perfil + rutina + métricas clave.
4. **Registro de sesión**
   - Fecha, peso, duración, notas.
5. **Visualización de progreso**
   - Gráfico de evolución y lista histórica.
6. **Mejora continua**
   - Ajuste semanal de volumen según nivel.
